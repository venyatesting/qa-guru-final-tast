# Проект "Нагрузочное тестирование Performance Shop"

Основная цель: подтвердить или опровергнуть наличие 3-кратного запаса производительности системы относительно пикового часа нагрузки.

## Тестируемая система

Приложение:	FastAPI (Python 3.11), 3 инстанса

Мониторинг:	Telegraf, Prometheus, Grafana

База данных:	PostgreSQL

Балансировщик:	Nginx

Запуск:	Docker Compose

## Материалы проекта

Build - Сборка приложения и необходимых метрик

Scripts - Сценарий нагрузочного тестирования

Docs - Документы

## Запуск и остановка приложения приложения

cd perfornance-shop

docker-compose up -d

docker-compose down --remove-orphans
